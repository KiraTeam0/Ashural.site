# موقع أشورال — محتوى بديل كامل

هذا المحتوى يستبدل **كل** ما بمستودع `KiraTeam0/Ashural`.

## قبل الرفع — خطوة واحدة إلزامية

افتح `index.html` وابحث عن `YOUR_FORM_ID` (سطر واحد)، وبدّله بمعرّف استمارتك
من [formspree.io](https://formspree.io):

1. افتح حساباً مجانياً ← New Form ← اربطه ببريد `info@ashural.com`
2. ينطيك رابطاً مثل `https://formspree.io/f/xabcdefg`
3. الجزء الأخير (`xabcdefg`) هو المعرّف — حطّه مكان `YOUR_FORM_ID`

**المعرّف ليس سرّاً** — يُنشر بالكود عادةً. أول رسالة تُرسَل يطلب منك Formspree
تأكيد البريد مرة واحدة.

إذا ما تريد الاستمارة الآن: احذف كتلة `<form ...>` كلها، والبريد والموقع
فوقها يبقيان ظاهرين.

## الملفات

```
CNAME                          ← ashural.com — لا تحذفه، بدونه ينكسر الدومين
index.html                     ← الصفحة الرئيسية
reayati/index.html             ← صفحة رعايتي الجديدة
reayati/nurses/index.html      ← صفحة الممرّضين
reayati/assets/                ← styles.css · app.js · updates.js
reayati/img/                   ← ١٨ لقطة (٩ مصغّرة + ٩ كاملة)
reayati/posts.json             ← آخر المنشورات
.github/workflows/instagram.yml
scripts/fetch-instagram.mjs
```

## قسم «آخر التحديثات» — اختياري

يتجدد كل نصف ساعة من إنستغرام. يحتاج مفتاحين بـ
Settings ← Secrets and variables ← Actions:

- `IG_USER_ID`
- `IG_ACCESS_TOKEN`

بدونهما الصفحة تشتغل كاملة، والقسم يعرض محتوى `posts.json` الحالي بلا تجديد.

## شنو انتغيّر عن النسخة القديمة

| التغيير | السبب |
| --- | --- |
| حُذف رابط «افتح نسخة الويب» (`app.ashural.com`) | مقفل بكلمة مرور — الزائر يصل باب مغلق |
| حُذف زر Google Play | التطبيق غير منشور — الرابط يعطي صفحة غير موجودة |
| الاستمارة تُرسل فعلاً | كانت تعرض «تم استلام رسالتك» بلا أن ترسل شيئاً |
| صفحة `/reayati` بالكامل | القديمة تعد بنسخة Play «قيد الاختبار» وتطلب تسجيلاً مقفلاً |
| أُضيفت `/reayati/nurses` | صفحة مخصّصة لشروط التسجيل والأمان |
| أُضيف معرض اللقطات | ٩ لقطات بنسبتها الأصلية ٤:٥ |

## بعد الرفع — افحص

1. `ashural.com` ← ماكو زر يودّي لتطبيق ويب مقفل ولا Google Play
2. `ashural.com/reayati/` ← الصفحة الجديدة ومعرض اللقطات
3. `ashural.com/reayati/nurses/` ← صفحة الممرّضين
4. أرسل رسالة تجربة من الاستمارة ← لازم توصل بريدك
5. الدومين شغّال (CNAME سليم)

⚠️ إذا كانت الصفحة القديمة اسمها `reayati.html` بالجذر، **احذفها** عند
الاستبدال — وإلا `/reayati` و`/reayati/` يصيران صفحتين مختلفتين.
